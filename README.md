# SMMly Examples

Small, focused examples for developers integrating with SMMly.

> **Status: Awaiting a verified public API contract.** No example in this repository should imply that an unreleased endpoint or integration is supported.

## Planned examples

- API authentication and request setup
- Service catalogue retrieval
- Order submission and status checks
- Balance and account workflows
- Error handling and retry behavior

Read the [current API release status](https://github.com/smmly-co/smmpanel-api/blob/main/CONTRACT-STATUS.md) before planning an integration.

Examples will be added only after the corresponding API behavior is implemented, tested, and documented in the [SMMly API repository](https://github.com/smmly-co/smmpanel-api).

Never commit credentials, API keys, customer information, or production configuration.
